# SANGEETA BENNE — Portfolio

Personal developer portfolio showcasing full-stack web applications, technical skills, and engineering experience in Java, Spring Boot, React.js, and SQL.

**Live site:** https://sangiportfolio.vercel.app/

Built during the placement training program at [KodNest](https://www.kodnest.com/) (full-stack development, AI and augmented reality training).

## Tech Stack
- **React 19**
- **Vite**
- **Tailwind CSS 4**
- **Framer Motion**
- **AOS (Animate On Scroll)**
- **EmailJS**
- **WebGL** (Interactive fluid splash cursor)

## Run Locally
```bash
npm install
npm run dev
npm run build
```

## Environment Variables
Create a `.env.local` file in the project root with the following variables:
- `VITE_EMAILJS_SERVICE_ID`
- `VITE_EMAILJS_TEMPLATE_ID`
- `VITE_EMAILJS_PUBLIC_KEY`
